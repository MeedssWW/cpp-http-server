How it works

            
    
                
  • Main thread runs accept() loop, waits for TCP connections
    • 
                
  • Each connection is dispatched to a thread pool via task queue
    • 
                
  • Worker threads parse HTTP, route the request, send the response
    • 
                
  • Cross-platform: Winsock2 on Windows, POSIX sockets on Linux/macOS
    •
